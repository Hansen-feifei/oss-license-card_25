一个面向中文初学者的开源许可证选择工具支持离线使用。。回答四个问题，在 30 秒内得到 MIT / Apache-2.0 / GPL-3.0 的推荐结果与理由，并附三种许可证的对比表。

## 为什么需要它

开源不等于"随便用"。没有许可证的公开代码，默认仍然是"保留所有权利"。而 GitHub 上最常用的三种许可证在专利、商标、衍生作品是否必须开源上差别很大，英文原文对初学者并不友好。本项目把这些差异压缩成一页中文速查卡。

## 功能

- 四问决策：根据使用场景、开源诉求、专利与商标关注点给出推荐
- 对比表：商业使用、闭源分发、专利授权、商标、传染性、典型项目六项对照
- 零依赖：单个 HTML 文件，双击即可在浏览器打开，无需安装、无需联网
- 可离线：适合课堂演示与社团分享

## 快速开始

1. 下载或克隆本仓库
2. 双击 `index.html`
3. 按提示勾选四个问题，点击"给出建议"

```bash
git clone https://github.com/USERNAME/oss-license-card_25.git
cd oss-license-card_25
```
